# news

金融新聞分析工具 — 面向「金融分析師水平」的可解釋新聞影響分析。

## 目標

不是堆關鍵詞或黑箱分數，而是能說清楚：

- 這則新聞影響誰
- 為什麼
- 幅度多大
- 置信度多高

每個結論都有依據（事實、傳導路徑、來源）。

## 核心功能

1. **用戶查詢**：貼上新聞 → 結構化分析師結論
2. **自動報告**：定時收集、去重、只展開高置信度事件（規劃中）
3. **可解釋**：事件類型、受影響標的、方向、傳導路徑、理由、置信度

## 架構（最小可用）

```
用戶輸入新聞 ──→ 事件抽取（LLM）──→ 影響推理 ──→ 結構化結論
                ↑
系統定時收集 ──→ 去重聚類 ──→ 同上 ──→ 日報 / 儀表板
```

## 快速開始

```bash
pip install -r requirements.txt
export OPENAI_API_KEY=your_key   # 或兼容的 endpoint
python -m src.query "貼上新聞內容"
```

詳細用法見 `src/query.py` 與 `src/analyzer.py`。
