# 本地開源爬蟲工具比較

以下工具均為開源，**本地部署不收費**（無官方按月 credits 或按次扣點）。

軟體本身免費，實際成本主要是自己的電腦、電費、網路帶寬，以及目標網站可能的限速／封鎖。

## 工具對照

| 工具 | 安裝後還要做什麼？ | 自己運行時，有沒有官方用量額度？ |
|------|------------------|------------------------------|
| **SearXNG** | 部署服務、設定搜尋引擎；完成後有搜尋網頁。接 Earlywinter 要啟用 JSON API | 沒有按月 credits；但上游搜尋引擎可能限速或拒絕請求 |
| **Trafilatura** | 安裝 Python 套件，就能用指令或程式抽取網址／HTML 的正文 | 沒有按次扣點或每月額度 |
| **Crawl4AI 開源版** | 安裝 Python 套件和瀏覽器元件，再用程式或自架服務爬取 | 沒有官方雲端 credits 限制；由自己的電腦執行 |
| **Scrapy** | 安裝後還要設定起始網址、編寫抓取與解析規則 | 沒有官方抓取額度 |

## 簡單結論

- **軟體授權 / 官方用量** → 完全免費
- **實際跑起來的成本** → 主要是你自己的電腦、電費、網路，以及可能被網站封鎖的問題

### 注意事項

1. **SearXNG**：本身免費，但依賴上游搜尋引擎（Google、Bing 等），那些引擎可能有自己的限制。
2. **Crawl4AI**：開源版本地跑免費；官方雲端服務才會有 credits。
3. **目標網站限制**：很多網站會擋爬蟲（IP 封鎖、驗證碼、robots.txt）。這不是官方額度，而是對方網站的限制。
4. **合法與服務條款**：爬取時請遵守各網站的使用條款與相關法規。

## 與本專案的關係

目前 `news` 專案主要使用 RSS / Atom / 官方 JSON API 與 Telegram 來源。若需要更深入的網頁正文抽取或自定爬取，可參考上面這些工具作為補充。

- Trafilatura：適合從已有 URL 抽取清潔正文。
- Crawl4AI / Scrapy：適合需要洋情渲染或自定爬取規則的場景。
- SearXNG：適合自建元搜尋來補充新聞搜尋。
